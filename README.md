# Interview AI — AI-Powered Interview Preparation

An AI-powered interview preparation application designed to help candidates practice interviews and improve their interview readiness.

## Overview

Interview AI is a full-stack web application built to explore AI-powered interview preparation, user authentication, and backend API development.

## Tech Stack

- Frontend: React.js, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Integration: Google Gemini API

## Features

- Interview preparation workflow
- Backend APIs for application functionality
- Database integration
- AI integration for interview-related functionality

> Note: Features listed above should match the functionality currently implemented in the project.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Lakshyashrivastava136/interview-ai-yt.git
cd interview-ai-yt
```

### 2. Install dependencies

Open separate terminals for the frontend and backend, navigate to their respective folders, and run:

```bash
npm install
```

### 3. Configure environment variables

Create the required `.env` file in the backend using the environment variable names expected by the application.

Never upload API keys, passwords, JWT secrets, or database credentials to GitHub.

### 4. Run the application

Check the `package.json` scripts in both folders and run the appropriate development commands.
